# simulation of the solar system
In the folder cppss you can find the codes to manage the architecture of the simulation and main.cpp to run the simulation.
You'll have to use the makefile to compile the codes and then launch it from command line with all the parameters needed (the different branches may have different parameters required because of sligth differences in the codes.
At the end of the simulation you can interact by command line to show data and graphs.
Data are automatically collected in some output files, but you can choose the folder by naming the outputfile when you launch the simulatuon.
You can also use the graphs.cpp file to re-analyse the data you've produced in one simulation and save the graphs too.
The folder "dati" contains the input files you can select for the simulation by command line.

In the folder pyss you can fiund the same codes but written in python and some graphs produced.

The code errori.py is a tool for data analysis, specifically for the comparison of different algorithms.
